Policy v1: This agent records foreground application names and approximate active/idle intervals during sessions you enable. Signals do not establish productivity. It collects no keystrokes, screenshots, clipboard, page content or browser history. Foreground collection may require macOS Automation permission; denial leaves application usage unknown. Website collection is unavailable without an extension. Raw records expire after 90 days by default. Offline queue is encrypted, retained for at most one hour, and never starts monitoring after restart.

Closing this application stops local collection. Attendance stays open. Network loss pauses collection; explicitly enable it after reconnecting.
